ServeIt

Serve any folder on your Mac as a local website, with one switch per server.

Requirements Build First server The window Menu bar Logs Troubleshooting

1. What you need

  • macOS 13 (Ventura) or newer.
  • Apple's Command Line Tools, which provide both Swift (to build the app) and /usr/bin/python3 (which the app runs to serve pages).

If you don't have the Command Line Tools yet, install them from Terminal:

xcode-select --install

Full Xcode is not required.

2. Build and launch

In Terminal, from the project folder:

./build.sh
open build/ServeIt.app

The build takes about 20 seconds the first time and creates build/ServeIt.app. To keep it handy, drag that app into your Applications folder.

Run ./build.sh again whenever the source changes. Quit ServeIt first, because the script replaces the app.

3. Start your first server

  1. Click Add New Server at the bottom of the window. A new row appears with a port already assigned (the first one is usually 8000).
  2. Choose what to serve: click the folder button and pick a folder, or type a path such as ~/Sites/my-page into the Folder field.
  3. Flip the row's switch on.
  4. Click Open in Browser. Your default browser opens http://localhost:8000/.

If the folder contains an index.html, that page is shown. Otherwise you get a listing of the files in the folder.

Repeat these steps to run several servers side by side. Each one gets its own port.

The menu bar item

ServeIt adds a server-rack icon to the menu bar at the top right of the screen. When servers are on, the number running is shown next to it.

  • Each server has a submenu with a Running toggle, Open in Browser, and Show Logs.
  • Stop All Servers switches everything off at once.
  • Open ServeIt Window brings the main window back after you close it.

Closing the main window does not quit the app, so your servers keep running from the menu bar. To stop everything, choose Quit ServeIt from the menu or press Cmd-Q.

Viewing logs

Click Logs on any row to open the ServeIt Logs window. It has one tab per server, labelled with the port and folder name.

  • Each page request appears as a line while it happens, and the view follows the newest line.
  • ServeIt adds its own markers when a server starts, stops, or exits.
  • Clear empties the tab.

Logs are kept in memory only and are gone when you quit the app.

Troubleshooting

You seeWhat to do
"Choose a folder to serve first."The Folder field is empty. Pick a folder, then switch on.
"Folder not found"The path doesn't exist or is a file. Check the spelling or use the folder button.
"Port … is already in use"Another program took the port after the row was created. Remove the row and add a new one to get a fresh port.
"Could not start python3"Install the Command Line Tools with xcode-select --install.
A permission promptmacOS asks before an app reads Desktop, Documents, or Downloads. Allow it to serve folders there.
A blank or old Dock iconmacOS caches icons. Quit and reopen the app.

Good to know

  • Servers are reachable only from this Mac (127.0.0.1), not from other devices on your network.
  • Your rows are remembered between launches, but every server starts switched off.
  • Quitting ServeIt stops all of its servers.
  • This is a simple development server. Don't use it to host a public site.
